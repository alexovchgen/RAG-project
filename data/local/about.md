# About this RAG assistant

This is a study assistant for the Classic ML cycle (weeks 7-10) of the
mentoring program. The corpus is official scikit-learn documentation
for the topics listed below, plus this about page.

## What topics I can answer questions about

- **Linear models**: ordinary least squares, Ridge, Lasso, ElasticNet,
  logistic regression, SGD, regularisation strategies, L1 vs L2.
- **Decision trees**: classification trees, regression trees, gini
  and entropy criteria, pruning, practical tuning tips.
- **Metrics**: confusion matrix, accuracy, precision, recall, F1,
  ROC AUC, log-loss, MSE, MAE, R², multiclass averaging.
- **Ensembles**: bagging, random forests, extra-trees, AdaBoost,
  gradient boosting, voting and stacking.
- **Cross-validation**: K-fold, stratified and grouped splits,
  shuffle-split, leave-one-out, cross_val_score / cross_validate.
- **Preprocessing**: scaling, normalization, encoding, polynomial
  features, discretization, custom transformers.
- **Pipelines and composition**: Pipeline, ColumnTransformer,
  FeatureUnion, transforming target with TransformedTargetRegressor.
- **Model selection / grid search**: GridSearchCV, RandomizedSearchCV,
  parameter grids, refit, nested cross-validation.
- **Imputation**: SimpleImputer, iterative / KNN imputers, missing
  indicators.
- **Feature selection**: variance threshold, univariate tests,
  RFE, SelectFromModel, sequential selection.

I respond in the same language as your question — English or Russian.

## What I CANNOT answer

Out of scope: deep learning, transformers, embeddings, agents,
time-series libraries, recommendation systems, computer vision,
and anything besides scikit-learn. If you ask — I will honestly say
I don't know from this corpus.
